# 🏁 Le Mans Onboard Wall

Watch loads of **FIA WEC / Le Mans onboard cameras at the same time**, on one screen — like a TV gallery or CCTV wall. Each box has a dropdown so you can switch to any car instantly. No more juggling twenty browser tabs.

![what it is](https://img.shields.io/badge/works%20on-Windows%20%26%20Mac-blue) ![browser](https://img.shields.io/badge/browser-Google%20Chrome-green)

---

## ✅ What you need

1. **Google Chrome** — works on **Windows and Mac**.
2. **Your own FIAWEC+ subscription** → https://plus.fiawec.com
   *This tool only arranges the streams — it does **not** give you access. Everyone who watches needs their own FIAWEC+ login.*

---

## ▶️ How to use it (about 60 seconds)

1. **Download** this project: click the green **Code** button above → **Download ZIP** → unzip it somewhere.
2. Open **Chrome** and **log in** at **https://plus.fiawec.com**. Leave that tab open.
3. **Open `index.html`** in Chrome:
   - **Windows:** double-click `index.html`.
   - **Mac:** right-click `index.html` → **Open With** → **Google Chrome**.
4. Each box has a **dropdown at the top** — click it and pick a car. They're grouped by **Hypercar / LMP2 / LMGT3**, and each shows the **drivers**.
5. If a box shows a **"WATCH LIVE"** button, click it once to start that feed.
6. To hear commentary, **unmute the one car you want** (the speaker control inside its player). The rest stay muted.

That's it. 🎉

---

## 🎛️ The buttons

| Button | What it does |
|--------|--------------|
| **➕ Add tile** | Add another box |
| **Layout** (top bar) | Choose a grid (2 / 3 / 4 columns) or a "big + small" cinema layout |
| **⛶ Fullscreen** (top bar) | Make the whole wall fullscreen (or press **F11**) |
| **⠿** (top-left of a box) | Drag to rearrange boxes |
| **⤢** | Make one box big |
| **⛶** (on a box) | Fullscreen just that one feed |
| **✕** | Remove a box |

The **bottom-right of each box** shows the **car number, team and drivers**. Double-click it to rename. The **Broadcast** group in the dropdown has the **World Feed** and a **Live Timing & Map** tile.

---

## 💻 Does it work on Mac?

**Yes.** It's just a web page — open `index.html` in Chrome on Mac the same way. (Safari works too, but Chrome is recommended.)

---

## ❓ "The boxes show a login/sign-up page instead of the car"

That means Chrome isn't sharing your FIAWEC+ login with the embedded players. Fix it by either:

- Making sure you're **logged in at plus.fiawec.com** in the **same** Chrome, **or**
- Allowing **third-party cookies for `plus.fiawec.com`** (Chrome → Settings → Privacy and security → Cookies).

---

## ⚡ Optional: auto-start (advanced)

By default you click **"WATCH LIVE"** once per box. If you'd like the feeds to start on their own, there's an optional Chrome extension included:

1. Go to **`chrome://extensions`**
2. Turn on **Developer mode** (top-right toggle).
3. Click **Load unpacked** and select the **`wall-extension`** folder.
4. Reload the wall — it auto-dismisses the gates and starts feeds **muted**.

> This bit is experimental and depends on your Chrome version. If it doesn't kick in, just click **WATCH LIVE** yourself — everything else works exactly the same.
